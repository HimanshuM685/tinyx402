# Quick start

tinyx402 gives scripts and AI agents [TinyFish](https://tinyfish.ai) web capabilities: search, page extraction, goal-driven browser automation, multi-source research, web-filled datasets and remote browsers. There are no API keys. Each request is paid in a stablecoin through the [x402 protocol](/docs/how-x402-works), on whichever [supported chain](/docs/networks) you choose.

## 1. Get a testnet wallet

Any EVM wallet works. Pick a chain and fund it:

- **Arc Testnet** (`eip155:5042002`) — test USDC from [faucet.circle.com](https://faucet.circle.com). Easiest: gas is USDC too, and you need none of it.
- **Whitechain Sepolia** (`eip155:1874`) — test USDT, which has to be requested.

Either way you need no gas token, because the facilitator submits the transfer. Full details: [Networks + facilitators](/docs/networks#getting-test-funds).

## 2. Try it in the browser

Open the [playground](/playground), connect your wallet and press **Run with x402**. You sign one EIP-712 message per request, and the result, payment status and transaction hash appear side by side.

## 3. Call it from code

```bash
npm i @x402/fetch @x402/evm viem
```

```ts
import { wrapFetchWithPaymentFromConfig } from "@x402/fetch";
import { ExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";

const account = privateKeyToAccount(process.env.PRIVATE_KEY);
// Every 402 offers each supported chain. Register the one you hold funds on.
const paidFetch = wrapFetchWithPaymentFromConfig(fetch, {
  schemes: [{ network: "eip155:5042002", client: new ExactEvmScheme(account) }],
  spendControls: {
    allowedAssets: [{
      network: "eip155:5042002",
      asset: "0x3600000000000000000000000000000000000000", // Arc Testnet USDC
      maxAmountPerPayment: "100000",
    }],
  },
});

const res = await paidFetch("https://your-domain.com/api/v1/search?query=example");
console.log(await res.json());
```

`paidFetch` behaves like `fetch`. When the server answers `402 Payment Required`, it signs the payment, retries, and returns the paid response.

## What it costs

Same base units on every chain, since both assets use 6 decimals.

| Endpoint | Price |
| --- | --- |
| `GET /api/v1/search` | <Price product="search" /> |
| `POST /api/v1/fetch` | <Price product="fetch" /> |
| `POST /api/v1/agent/run` · `/run-sse` | <Price product="agent" /> |
| `POST /api/v1/research` | <Price product="research" /> (deep), 0.5 (max) |
| `POST /api/v1/datasets` | <Price product="datasets" /> per target row |
| `POST /api/v1/browser` | <Price product="browser" /> |

<Callout>
You are only charged when a request succeeds. Invalid input (`400`), failed agent runs, upstream failures (`502`/`503`) and anything else that returns a status of 400 or higher are never settled. Research and Datasets settle when the job is **accepted**, because they keep running in the background. [Error codes →](/docs/errors)
</Callout>
