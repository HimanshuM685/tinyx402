## Picking an endpoint

- **You know the URL** → `fetch`. Pass `purpose`, and use `include_selectors` to scope the extraction.
- **You need URLs** → `search`, then `fetch` the best hits.
- **Interaction needed** (clicks, forms, pagination) → `agent/run`, with an `output_schema` so the result is typed.
- **Open question across many sources** → `research`, then follow `events_url`.
- **Many entities with the same fields** → `datasets`, then read `rows_url`.
- **You want to drive the browser yourself** → `browser`, then `chromium.connectOverCDP(cdp_url)`.

## Budgeting

A `maxAmountPerPayment` of `200000` (0.20 USDT) covers every fixed-price endpoint and deep research. Use `50000` to exclude research. Datasets cost `20000 × target_rows`, so set the cap to fit. Agents can read the exact price from the `402` response before paying.
