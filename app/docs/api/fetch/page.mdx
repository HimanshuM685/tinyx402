# Fetch

Clean, readable content from one or more URLs. Navigation, ads and boilerplate are stripped with Mozilla Readability, and the result comes back as Markdown, text or HTML.

<Endpoint method="POST" path="/api/v1/fetch" product="fetch" />

One payment covers up to 10 URLs. You are charged only if at least one succeeds.

## Body

| Field | Type | Default | |
| --- | --- | --- | --- |
| `urls` | string[] | — | Required. 1–10 public http(s) URLs. |
| `format` | `"markdown"` \| `"text"` \| `"html"` | `"markdown"` | |
| `render` | boolean | `true` | Render in a real Chromium (runs JS). `false` uses a plain HTTP fetch, which is much faster. |
| `links` | boolean | `false` | Include up to 200 absolute links. |

## Example

```ts
await paidFetch("https://your-domain.com/api/v1/fetch", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ urls: ["https://en.wikipedia.org/wiki/HTTP_402"], render: false }),
});
```
