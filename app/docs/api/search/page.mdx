# Search

Ranked web results (titles, snippets and URLs) from TinyFish Search, ready for an LLM or for code to consume.

<Endpoint method="GET" path="/api/v1/search" product="search" />

## Query parameters

| Name | Type | |
| --- | --- | --- |
| `query` | string | **Required.** 1–2000 chars. |
| `purpose` | string | Why you are searching. Gives the ranker more to work with. Max 2000 chars. |
| `location` | string | Country code for geo-targeted results, e.g. `US`, `DE`. |
| `language` | string | Result language, e.g. `en`. |
| `domain_type` | `web` \| `news` \| `research_paper` | Defaults to `web`. `news` adds publisher and date. `research_paper` adds authors, venue, year and citations. |
| `include_domains` / `exclude_domains` | string | Comma-separated domain lists. |
| `recency_minutes` | integer | 1–5,256,000. Don't combine with date filters. |
| `after_date` / `before_date` | `YYYY-MM-DD` | Calendar window. Not supported for `research_paper`. |
| `pub_year_min` / `pub_year_max` | integer | Publication-year window, `research_paper` only. |
| `page` | integer | 0–10. |
| `include_thumbnail` | `true` \| `false` | Adds `thumbnail_url` where available. |

## Example

```ts
const res = await paidFetch("https://your-domain.com/api/v1/search?query=web+automation+tools&location=US");
```
